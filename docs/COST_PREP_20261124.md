## The one money hole found and closed today
The gateway counts dollars only when `PK_AI_PRICE_IN_PER_M` and `PK_AI_PRICE_OUT_PER_M` are set. Without them the two dollar caps counted nothing and only the 200 calls per day held. `deploy/entrypoint.sh` now refuses to start the gateway unless both prices are set and prints an `ERROR` line when AI credentials are present without them. Checked in two real container runs (`(not published)`): with `AWS_REGION` set and no prices the gateway does not start and `/ai/health` answers 502; with no AI variables nothing about AI is printed and the page and relay answer 200. A static rule and tests keep it from coming back (`scripts/check_coolify_deploy.py`, `scripts/test_check_coolify_deploy.py`).

## Recommended settings (the owner decides)
| Variable | Contest build suggestion |
|---|---|
| AI gateway | leave it off unless the video needs the online opponent; the three built-in opponent levels need no key |
| `PK_AI_PRICE_IN_PER_M`, `PK_AI_PRICE_OUT_PER_M` | the dollar prices per million tokens from the official Bedrock price page (required to switch the AI on) |
| `PK_AI_DAILY_CAP`, `PK_AI_DAILY_USD`, `PK_AI_TOTAL_USD` | if on: 100 calls, 0.50, 5.00 (smaller than the defaults of 200, 1.00, 20.00) |
| `PK_AI_STATE_DIR` | a persistent folder, or a redeploy resets the total |
| `PK_ALLOWED_ORIGINS` | `https://<public host>` (without it the relay answers 403 to real players) |
| `PK_RELAY_TRUST_PROXY=1` and `PK_RELAY_MAX_PER_ADDR` | only if the server really sits behind Cloudflare; otherwise every player looks like one address |
| Kill switch | delete the AWS variables (or the two prices) and redeploy: the gateway stops and the game keeps its built-in opponents |

## What only the owner can do (the steps that spend or hold money)
1. Pay for or confirm the Contabo plan and the domain.
2. If the online opponent is wanted: create AWS credentials or a role, enable Bedrock access for the one model, set the variables above as Coolify secrets.
3. Set the Coolify variables and trigger the deploy.
