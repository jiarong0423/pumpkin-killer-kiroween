## What we learned so far (rules for the next prompts)
1. A style reference picture beats a style sentence; give style first and identity second, and say "first reference / second reference" in the prompt (Kiro 79).
2. Keep the subject and the action in `prompt`, the look in `style`; do not repeat the style in both.
3. Edit from the ORIGINAL picture, never from an already edited one: noise accumulates (P03).
4. Ask for a flat, noise-free magenta background, then key with a tight ramp and cut the glow halo (P01).
5. One picture per prompt; sprite sheets of many cells are not kept consistent by Qwen.
6. Do not put text in a picture (Qwen writes Chinese unreliably): the coin back shows a stem and vine, not the character 字.
7. A fused LoRA works where a live LoRA on fp8 weights does not (P05).
8. Judge every result against its references with the measured checks (background noise, halo width, palette, scale) in scripts/score_ghost_tests.py, not only by eye.
