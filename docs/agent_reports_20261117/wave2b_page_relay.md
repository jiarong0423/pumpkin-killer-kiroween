## 2. What I built (all behind `relayLive()` = relay `start` received, page is a human seat; local play never reaches it)
- Ready/start: `startRelayMatch` (sends `ready` with `units`; host adds `teamSize`; agent seat keeps the QR curtain), `beginRelayMatch` (opponent hero from `room_state.seats`/`start.heroes`, room scene, opener from relay phase, `firstOpener`). `room-create` now sends the picked scene and makes the right seat a human seat.
- Turn order follows the relay: `relayAfterAttack` / `relayAfterTurn` (reuses `openerOfRound`, so rooms alternate the opener like the relay), `relayWhenMyTurn` waits until `state()` says (round, phase) is mine, `relayEndTurn` sends `end_turn` (also on timeout and hallucination skip), `relayWaitRemote`.
- Remote action: `relayApplyAction` runs the same `executeThrow` with the message's angle, power, `start` (`relayForcedStart`), dirX; `kind: ultimate` arms the remote ultimate; `move` replays the die in `stepDice` (`d.remote`); `claimed_landing` is checked within 4 px against `relayFlightLanding` (the page's own `predictPath`; `Flight` is not loaded by the page).
- Judge: `relaySendJudges` (victim device: one judge per own unit that lost hp, else a miss, `ref` = action seq), `relayCompareJudge` (attacker compares, shows `relay.outOfSync`, never hides). Hash: once per round in `resolveRound` (`TEAM_N > 1 || relayLive()`), per-attack hash skipped in rooms.
- Determinism needed for equal state: round wind from `Determinism.wind`; `relayStream` for shuriken spread (mirrored in leftward flight), shield bounce, shock, lifesteal, nun pick; stun/slow of the remote copy handled at its turn start (`relayRemoteStatuses`) and the left side's start-of-turn statuses moved after the round hash in rooms.
- Not in rooms yet (message `relay.noItems`): items, supply, shield/defend, knight and necromancer ultimates (hidden placing / clock). A finished room is closed (`endRelayRoom`, play again = local). Team matches use the same code path (unit ids `u.id`, team hash).
