## 3. How to verify a license before use

1. Open the asset page in a browser (not a search snippet or a mirror).
2. Read the license field on that page, and the uploader's description and
   comments. Note any doubt, such as a commenter questioning the license.
3. Check the attribution rule for that license: whether credit is required, what
   wording, and where it must appear. For CC-BY 4.0, credit is required. For
   CC0, none is required, but we still credit as a courtesy where easy.
4. Save a screenshot, or the URL with the date and the license text you saw, in
   `(not published)` (one file per asset, named after the asset).
5. Never mix GPL or other copyleft material into the repo. If the license is
   unknown, unclear, non-commercial, or disputed, do not use the asset.
