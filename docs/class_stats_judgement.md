## 2. 模型與假設（所有期望值都由這裡來）

- **命中模型**（任務指定）：投射物在 |dx| <= 70 px 且進入 190 px 高的身體框才算命中。我把落點誤差當成「以目標為中心的均勻分布 +-A」，單點投射物命中率 P = 140 / (2A)。
  - **AI 型（A = 210 px）**：P = 0.333。來源：index.html 的註解寫 AI 誤差 14 力度單位約 33%；ultimates_design.md 用同一個模型。
  - **機器人型（A = 100 px）**：P = 0.70。來源：playtest 的機器人誤差 +-5 力度單位約 +-100 px，骷髏實測 71%，與 0.70 吻合。
  - 真人在兩者之間。
- 身體框高度 190 px 會讓陡降的彈道多出最多約 136 px 的有效寬度。**我忽略它**，對所有點投射物職業相同；只有盾衛的落地小跳（第 3 節）會用到身體框的高度。
- **機器人型的修正係數 0.88**：柵欄擋掉約 12%，風的殘留誤差。實測/模型：骷髏 14.3/16.8 = 0.85，巫師 18.2/19.6 = 0.93。
- **期望傷害 EDT**（一次出手，單一目標）= P x 典型傷害。大範圍職業的 P 用判定寬度 / (2A)，上限 1。
- **強度指標 Power = HP x EDT**。理由：兩個職業對打時，A 殺 B 的平均出手數 = HP_B / EDT_A，B 殺 A 的是 HP_A / EDT_B，兩者之比 = (HP_A x EDT_A) / (HP_B x EDT_B)。所以 Power 相等就是公平的平均。
- 霜咒修正：骷髏命中後，對手下 2 次出手傷害 x (1 - c)。對手被詛咒的比例 cov = 1 - (1 - p)^2（p 為骷髏命中率）。骷髏的等效倍率 = 1 / (1 - c x cov)。
- 處決修正：死神在一場對打中，約 22% 的出手發生在目標 30% 血以下，倍率 1 + 0.5 x 0.22 = 1.11（手算估計）。

## 3. 盾衛（骰子 1 到 6）：手算與落地的處理

規則（讀 index.html 的 projectile 迴圈）：骰出 N 次碰撞，每次單位命中造成 30/N。撞單位時，若還剩碰撞，彈一個小跳（vx x -0.12，vy = -330，約 0.67 秒）落回；撞地（還剩碰撞）：往前滑跳一次（vy x 0.55，vx x 0.75），**沒有傷害但耗一次**；撞柵欄：耗一次、沒有傷害、反彈回來。最後一次碰撞無論撞到什麼都結束。

**落地時會發生什麼：**
- N = 1 且第一個接觸是地面：0 傷害。
- N >= 2 且第一個接觸是地面：往前滑跳約 428 px（弧高 <= 108 px，低於身體框 190 px），所以只要目標在落點前方 70 到 498 px 內，滑跳會打到目標。這讓「短彈」也能造成傷害（短側有效窗口約 568 px，其他職業是 140 px）。但這次命中之後只剩 N - 2 次碰撞，所以最多 30 x (N - 1) / N。
- 風與小跳：小跳每次約被風推 16 x |風| px。身體框半寬 70 px，所以在風 2 左右小跳 3 次後就可能飛出框外，剩下的碰撞變成撞地、白白耗掉。

手算（假設風在 -5 到 5 之間均分、命中位置在身體框內均分）：

| N（骰子） | 1 | 2 | 3 | 4 | 5 | 6 | 平均 |
|---|---|---|---|---|---|---|---|
| 直擊後實際落下的傷害（總量 30） | 30 | 24.1 | 20.5 | 17.6 | 15.4 | 13.7 | **20.2** |
| 先落地滑跳再打到的傷害 | 0 | 15 | 12 | 9.8 | 7.8 | 6.8 | **8.6** |

連續命中次數 K 的分布（直擊後）：P(K >= 1..6) = 1、0.61、0.44、0.30、0.22、0.18。
- AI 型：EDT = (1/3) x 20.2 + (1/3) x 8.6 = **9.6**（長彈 1/3 沒傷害）。
- 機器人型：0.70 x 20.2 + 0.15 x 8.6 = **15.4**。
- **實測**：playtest 在 22 總傷害時平均 7.4，換成 30 約 10.1。手算 15.4 比實測高約 50%，我**不能解釋這個差**（可能是柵欄、角度、風的方向、我沒模擬的小跳細節）。因此盾衛的 Power 用範圍表示：AI 型 580（實測換算）到 1152（手算），機器人型 1212 到 1848。
- 若把小跳「釘在原單位上」（不受風），直擊永遠 30、滑跳後 15 到 25，AI 型 EDT 約 15.9，Power 約 1900，明顯過強。**所以不要這樣修。**
