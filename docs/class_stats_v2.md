**擊退規則（建議全部照做）：**
1. 只在斧頭**直擊單位**時發生。撞柵欄、撞地、被天空盾擋下都不擊退。致命一擊不擊退。
2. 方向沿 x 軸遠離投擲者（怪人是玩家時被打者往 +x，怪人是 AI 時往 -x）。距離固定 50 px，不隨傷害變。
3. 被限制在被打者允許的移動範圍內：人類 160 到 760，AI 1160 到 1760。已在邊界時不動（距離縮短到 0 到 50）。**不會把任何單位推出範圍，也不會推過柵欄**（柵欄在兩個範圍之外）。
4. 4 打 4 時，與同隊下一個單位至少保持 160 px，擠到就停。
5. 會改變下一回合的距離：被打者留在新位置，**不耗掉他自己的「每回合一次移動」**。公開狀態的 x 會更新，AI 看到的是新位置（沒有隱藏資訊）。
6. 0.25 秒滑動演出，在 hit-stop 之後。
7. 大招不加額外擊退（維持每次 50 px），避免發明新數字。

**擊退值多少錢（手算，沒放進 Power）：**
- 被推開後，被打者原本校準好的力度會短 50 px。對命中窗口 +-100 px 的好手大約損失 14% 的下一次命中（窗口 200 對 140 的重疊 120 / 200 = 0.6，原本 0.7）；對 +-150 px 以上的人幾乎沒影響（窗口仍完全包住 140）。平均約等於對手下一次出手期望傷害 -5%，折成怪人 Power 約 +3%。
- 反作用：連續擊退會把對手推向後方邊界，5 下共 250 px。對手貼到 1760 後間距可到 1600，超出怪人 54 度射程，**怪人必須自己追上去**。擊退因此有自我限制，所以我建議採用。
- 我**沒有**把擊退拿來換更高傷害：Power 已在帶內（第 5 節），再加傷害會讓怪人偏強。

## 4. 模型與假設（與 judgement 的差異用粗體）

- **命中模型**：落點誤差視為以目標為中心的均勻分布 +-A px；單點投射物命中率 P = 140 / (2A)。**加一項：誤差以力度單位計，所以 A_eff = A x 速度係數**（慢的武器同樣的力度誤差換成較小的落點誤差；推導：落點對力度的斜率 = 2R / 力度，而同一距離所需力度 ∝ 1 / 速度係數）。judgement 沒有這一項，對新娘 0.9 與怪人 0.85 各多 11% 與 18% 命中率。
- **三種技術水準：**A = 210（AI 型，P = 0.33，index.html 註解的 33%）；**A = 150（P = 0.47，對應 playtest_fixes 在 37 次 AI 投擲量到的 46%）**，這是主要參考；A = 100（機器人型，P = 0.70，骷髏實測 71%）。
- **Power = 血量 x 每次出手期望傷害（EDT）**。兩個職業對打時平均殺死對方所需出手數之比等於 Power 之比，所以 Power 相等就是公平的平均。
- **霜咒修正**：骷髏命中率 p 時，對手被詛咒的比例 cov = 1 - (1 - p)^2；倍率 = 1 / (1 - c x cov)，c = 0.15。**c 從 0.20 降到 0.15。**
- **處決修正**：**倍率 1.08（judgement 是 1.11）**。算法：處決只在目標血量落在 (普攻, 30% x HP] 時能少打一下，窗口長度 (0.3 HP - 23) / 23 在七個 HP 平均約 0.38 下，平均殺人 5 下，所以 5 / (5 - 0.38) = 1.08。
- **盾衛**：沿用 judgement 的手算（直擊後平均落下 20.2 傷害、先落地跳再打到 8.6）與 playtest 實測換算（實測約為手算的 0.66 倍），Power 取中間值並標出範圍。實測與手算的差距**仍然無法解釋**。
- **新娘**：命中率 = min(1, 210 / (2 x 0.9 A))，命中時平均衰減係數 0.83（A = 100 時 0.88，因為落點被限制在半寬 90 內）。
- **怪人**：命中率 = 70 / (0.85 A)。
