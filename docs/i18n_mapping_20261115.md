## Format decisions
- Keys use camelCase segments, not snake_case: `scripts/test_i18n.js` only allows letters, digits and dots.
- Placeholders are `{name}` (what `i18n.js` replaces), not `${x}`. Each placeholder is named after its meaning.
- Locale codes: `zh-TW` and `en`. Namespaces follow the test: `hud.round`, `gameover.win`. `lang.title` and `lang.label` (allowed by the test) are NOT created: no such text exists in the source.
- Kinds: label = visible words (buttons, HUD, names, headings), title = tooltip / aria / page title, blurb = hero description, help = help pill and how-to hints, toast = floating text on the canvas.
