# Kiro task 15 - asset candidate sheet (read and write files only, no images, no downloads)

## Why
Pumpkin Killer (Kiroween Costume Contest) needs final art. The final art is generated by the owner on Colab, never by Kiro and never faked by code.
Free third-party assets may only serve as placeholders or style references, and only if the license is clean. The owner wants one honest table of
what exists and what each license really allows, so the Devpost write-up never claims more than we have rights to.

## Do exactly this
1. Read `docs/game_mode.md` (the four classes and what they throw) and `docs/ROLES.md`.
2. Write `docs/asset_candidates.md` with:
   a. A table of the candidates below. Columns: name, URL, what it contains, license as stated in the search snippet, `verified` (always "NO - snippet only" because you cannot browse), risk (LOW / MEDIUM / HIGH) with a one-line reason, and the allowed use (placeholder only / style reference only / do not use).
   b. A second table "what the game needs" with the four classes (skeleton, bat, knight/guard, pumpkin wizard) x the items they need (body, thrown item, hit pose, portrait, projectile) and which candidate could cover it as a PLACEHOLDER (or "none").
   c. A section "How to verify a license before use" in 5 steps (open the page, read the license field, check the attribution rule, save a screenshot or URL with date into `(not published)`, never mix GPL material into the repo).
   d. A section "What the write-up may say" with 3 plain sentences that stay true even if no candidate is used.
3. Also write the Kiro spec `.kiro/specs/asset-candidates/` (requirements in EARS form, design, tasks). Keep it short: the sheet is the deliverable, the spec says how it is kept current.
4. Do not create, download or copy any image. Do not touch `index.html`, `assets/`, `scripts/`, `js/`. Do not use git.
5. Finish with a 6-line summary and say anything you could not do.

## Facts to respect
- The game's art style is the owner's reference mockup (`(not published)`), not pixel art; pixel-art assets would clash. Say so in the risk column where it applies.
- The Kiroween rules require third-party assets to be authorized. If a license cannot be shown, the answer is "do not use".
- Never invent license text. If you do not know, write "unknown".
