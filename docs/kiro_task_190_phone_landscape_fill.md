## What the main line measured on the real phone (Realme RMX2075, 1080 x 2400 px, Chrome WebApk window, landscape; screenshots `phone4.png`, `phone5.png` in the main line scratchpad)
1. Owner: "too much empty space" ("留白太多"). The game covers only the middle 66 percent of the width (x 350 to 1670 of 2000 in the screenshot); about 17 percent black on each side.
2. The bottom is CUT OFF: the dock (angle/power/skill buttons) is half hidden. Cause: `body` is `100vh` and `#game-container` is `min(100%, 1400px, (100vh - 24px) * 16 / 9)`; in a WebApk/Chrome window with a title bar `100vh` is taller than the visible area, so the stage is sized for a screen that does not exist. Use `100dvh` and `window.visualViewport` (resize + scroll listeners), never bare `100vh`.
3. The title bar of the WebApk window itself takes about 25 percent of the height (localhost is not in the app scope); that disappears on the hosted https page, but the page must also look right with it present.
4. Overlaps at a phone size: the two name plates (hero name overlaps the "100" and a long number string such as "2000000…" appears over the left HP plate on round 8: find out what draws it, probably a floating damage/heal text or the HP number animation, and fix the cause), the top buttons (sound, restart, language, "?") sit on the centre countdown board, the dock is cut.
