# Kiro task 23 - can Colab generate the sounds? options, licenses, prompts, a Colab job (web allowed, files only)

## Why
The owner asks whether Colab (A100 40 GB, already used for the art) can synthesize music and sound effects, and wants YOU to say what is possible, what is safe to use in a contest, and to prepare the generation job.
The contest rule: third-party assets and models must be authorised; the final art is already generated on Colab; Kiro never generates media itself. You have web search and web fetch. Do not download any model or audio and do not run anything.

## Do exactly this
1. Read `docs/audio_event_map.json` (the 30 events and the music layers), `docs/sound_design.md`, `docs/audio_sources.md`, `colab/pumpkin_assets_job.py` (the existing Colab job style, for reference).
2. Research on the real pages (record `opened: yes/no`): text-to-audio / text-to-music models that can run on a Colab A100 40 GB, at least: Stable Audio Open 1.0 (and Small), MusicGen (Meta, via transformers/audiocraft), AudioLDM 2, Tango / Tango 2, and any newer open model you find that is better for short game sound effects.
   For each: who publishes it, the weights license and the code license as written on the model page (quote at most 10 words), whether outputs may be used commercially / in a contest entry, restrictions (revenue limits, non-commercial, attribution), max clip length, sample rate, VRAM, speed on an A100, typical quality for short SFX vs music loops, and how to run it (library and one-line install). Be explicit about NON-COMMERCIAL licenses.
3. Write `docs/audio_generation_options.md`: (a) the model table; (b) a verdict: which model(s) are safe to use for this entry and why, which must not be used, and what the owner should check on the license page before generating (list the exact page URLs); (c) honest quality notes: what AI audio models do well (ambient beds, whooshes, impacts, magic shimmers) and badly (precise short clean hits, looping seams, tempo) and how to fix with editing (trim, fade, loop crossfade; these edits can be done by a script with numpy, no model); (d) a section "What Kiro can do for sound": design the prompts and the mix, write the Colab job and the post-processing and loop-check scripts and the tests, wire the module; what Kiro cannot do: hear the result, run Colab, download.
4. Write `colab/audio_jobs.json`: one entry per event in the event map (30) plus the music layers (bed, tension drone, victory sting, defeat sting): id, prompt (short, concrete, Halloween dark-fantasy, e.g. "short whoosh of a thrown spear, dry, no music, no voice"), negative prompt, duration seconds, number of variants (3), seed base, loop (true/false), and the post-processing (trim silence, fade 5 ms in / 30 ms out, normalise to -3 dBFS, loop crossfade 80 ms where loop is true). Keep every prompt free of artist, brand and game names.
5. Write `colab/audio_job.py`: a Colab cell script in the style of `colab/pumpkin_assets_job.py`: installs the chosen model library, mounts Drive, reads `audio_jobs.json` from `MyDrive/PumpkinKiller/inputs/`, generates each variant, post-processes (numpy / soundfile only), writes WAV to `MyDrive/PumpkinKiller/audio_out/<id>_v<N>.wav`, skips finished files, prints OK / ERR lines and a final count, never stops on one failure. Model name and license note at the top as constants. It must be correct code but it is NOT tested (state so). Choose the model that your verdict marks as safe.
6. Write `scripts/postprocess_audio.py` (local, numpy + soundfile / wave only): the same post-processing so the owner can also fix files after downloading; plus `scripts/test_postprocess_audio.py` with synthetic signals (silence trim, fade, normalise, loop crossfade length) and run it (`python3 -B scripts/test_postprocess_audio.py`); report the real last line.
7. Write the spec `.kiro/specs/audio-generation/` (requirements in EARS form, design, tasks).
8. Do not download or run models. Do not touch `index.html`, `assets/`, `js/`. Do not use git. Do not create images.
9. Finish with a 7-line summary: how many pages you really opened, the verdict in one line, how many prompts, what you could not verify.
