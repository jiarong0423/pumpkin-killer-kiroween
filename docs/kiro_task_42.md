## Module 1 - js/ultimate.js: the ultimate ledger (spec name: ultimate-ledger)

Rules (from docs/ultimate_rules.md and the owner log): a successful hit adds ONE pip per throw (same throwId never counts twice); pips cap at 3; each side counts its own; at most 2 uses per side per match; arming only on the side's own turn (ctx = { turn, side, round, defendTurn, dead }), never on a defend turn, never when dead, at most one use per side per round, a lockout rule exactly as ultimate_rules.md; armed state can be cancelled; consume() spends the ultimate on release even if it misses, resets pips to 0 and increments uses; a KO'd unit loses its pips.
