# Kiro task 64 — the scripts that take the owner's image2 sprite sheets and turn them into game-ready, checked frames

Context (owner 2026-11-10): the owner pastes Kiro-written prompts into OpenAI's image model (image2) with a reference picture, and downloads sprite sheets / strips (a grid of consecutive animation frames on a flat magenta #FF00FF background). The files land in a folder the owner chooses and I (the main line) re-run your scripts to verify everything myself. You write ALL the scripts and their tests; you are the 'Codex inside Kiro'. Standard library plus numpy, Pillow, OpenCV (cv2) and scikit-image only (all installed). No network, no API calls.

Read first: docs/pose_spec.md (the standard: 8 frames per class, one direction, one hand, one size, feet on row 1000 of a 1024x1024 transparent canvas, face lock), scripts/ingest_queue.py (how single pictures are keyed, rejected when they touch the edge, aligned and installed), scripts/pose_similarity.py (decoupled measures: palette, face, scale, pose_diff, lean; thresholds), scripts/check_pose_set.py, scripts/make_review_html.py (the review page pattern), (not published) (newest rows last).

Write, in scripts/:
1. `ingest_sheets.py`: input a folder of sheets named `<class>_sheet.png` (a grid of ROWS x COLS cells, grid given by `--grid 4x2` or detected from the magenta gutters), `<class>_strip_<name>.png` (one row of N frames) and `<class>_portrait.png`. It cuts the cells, keys the magenta (tight keying as in ingest_queue.py), rejects a cell that touches its cell edge, normalises every cell onto the standard 1024x1024 canvas (feet on row 1000, centred on the opaque box, NO rescale: the size is part of the check), and writes assets/poses/<class>_<frame>.png by a frame-name table you define from docs/pose_spec.md (idle1, idle2, charge1..3, release, empty, hit and the longer strips idle_loop_1..4, charge_1..6, throw_1..5, hit_1..3). It never overwrites an existing file without `--force` and always keeps the replaced file under (not published)<timestamp>/. One log line per cell; exit 1 when anything was rejected.
2. `check_continuity.py`: for the ordered frames of a strip, measure each consecutive pair with the decoupled metrics of pose_similarity.py (face_sim, face_orb, palette_sim, scale, head_scale, pose_diff, feet shift in px, the opaque-box centre shift) and flag a JUMP when a pair differs much more than its neighbours (use the median step of the strip and flag steps above 3 times the median or any face/scale/feet violation), the loop closing step (last to first of an idle loop), and a COPY when two non-adjacent frames are nearly identical. Output a table plus a JSON file; exit 0 always (it reports).
3. `make_strip_gif.py`: an animated GIF preview per strip over a dark backdrop (frame times configurable, loop), plus a contact sheet PNG with the frame names and the flags from check_continuity.
4. `run_ingest_pipeline.sh` (bash, no sudo): the whole chain for a folder: ingest_sheets, check_pose_set, check_continuity, make_strip_gif, make_review_html-compatible thumbnails, one summary at the end, with every step's exit code printed.
5. Tests: `scripts/test_ingest_sheets.py` with synthetic magenta sheets made in the test itself (a coloured figure per cell): the cut, the keying, the edge rejection, the baseline alignment, no overwrite without --force, the replaced-file backup, the frame-name table, a jump and a copy detected by check_continuity, a gif written. Run it with `python3 -B scripts/test_ingest_sheets.py` until it passes; nothing may touch the real assets/ in the tests (use a temp directory).
Rules: scripts must be complete (no placeholders), log to a file and stderr, failures print ERROR and return non-zero. Do not edit any existing script or index.html. State what you could not verify (you cannot see images).
