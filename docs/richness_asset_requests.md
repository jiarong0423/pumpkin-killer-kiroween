# Richness asset requests for Colab (Kiro task 34)

New images for the **top 8 items** of `docs/richness_plan.md`, highest impact first. These must be made on Colab (Qwen-Image-Edit) and never faked with code. Nothing here has been generated or checked, and I cannot see images, so every size and every look is a guess to review in the game.

Conventions (same as `docs/airdrop_asset_requests.md` and `colab/jobs.json`): flat solid magenta background `#FF00FF` (chroma-keyed afterwards), no text, no watermark, no cast shadow outside the object, dark-fantasy 2D cartoon art with thick clean outlines, facing left where a direction exists. Palette: stone `#2a2337`, wood `#4a2e1a`, candle gold `#ffcf5a`, pumpkin orange `#ff8a1f`, spectral cyan `#5df2ee`, violet `#a98bff`.

Two notes for the keying step:
- Fog and steam are drawn as **opaque painted shapes** (no soft see-through edges). Soft edges keyed from magenta leave a pink fringe. The game fades them with alpha in code.
- Sheets use a 16 px magenta gutter between cells so the cells can be cut on a fixed grid.
