# Roster asset requests for Colab (Kiro task 33)

New art for the two new classes (Plague Doctor, Lantern Warden) and one shared tombstone. Design and numbers: `docs/roster_design.md`. I made no images and downloaded nothing.

Not repeated, because it already exists: the four unit images (`assets/units/`), skeleton and bat poses (`assets/poses/`), the spear, shuriken, small shield and pumpkin projectiles, the fx sprites (ghostfire, rune circle, stardust, spirit mist, impact flash, poison bubbles), and the portraits and cut-ins of the four existing classes (already item 4 and 5 in `docs/dock_asset_requests.md`). The lantern burst can reuse `fx_rune_circle` and `fx_ghostfire`, the poison puddle can reuse `fx_poison_bubbles`, so no effect art is requested.

Conventions (same as `docs/dock_asset_requests.md` and `colab/jobs.json`): flat solid magenta background `#FF00FF` for chroma keying, no text, no watermark, no cast shadow outside the object, dark-fantasy 2D cartoon art with thick clean outlines, same style as `assets/units/unit_knight.png` (use it as the style reference). Characters and poses face LEFT (the game mirrors them for the other team); portraits face right, as in the dock request. Characters must fit a body box of about 140 x 190 px at the game's 220 px sprite size, so keep the silhouette compact and centred.

Order: highest priority first. Pose items need the approved idle image as the reference, so idle comes first.
