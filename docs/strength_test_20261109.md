# 強度測試紀錄 2026-11-09（主線；平衡模擬器 scripts/sim_balance.js）

方法：每個配對 100 到 200 場，種子 7 與 11，全部 7 個職業，數值為 Kiro 的 v2 建議值，盾「落地就結束」規則。**限制（owner 指出）：模擬裡的機器人知道精確的風與座標，等於「抓座標犯規」，所以命中率偏高、勝率只能看相對強弱；Kiro 任務 46 與 45 已加上「只看人眼看得到的資訊」的感知層，之後要重跑。**

| 職業 | 對其他六個職業平均勝率（誤差 9／14） | 要打幾下 | 每次出手期望傷害 |
|---|---|---|---|
| 骷髏長矛兵 | 63.3%／52.3% | 4.7 | 21.9 |
| 南瓜巫師 | 50.8%／46.5% | 4.1 | 25.7 |
| 蝙蝠刺客 | 49.3%／47.3% | 4.3 | 23.9 |
| 南瓜盾衛 | 43.0%／37.5% | 5.4 | 18.0 |
| 鬼娃新娘 | 27.8%／37.1% | 5.1 | 18.4 |
| 鐘樓怪人 | 59.8%／74.4% | 5.6 | 18.9 |
| 死神 | 55.8%／54.9% | 4.7 | 21.5 |

重點：超出 40 到 60% 範圍的配對 16 個（誤差 9）／15 個（誤差 14）。最弱：新娘（尤其對怪人 10%）、盾衛（對怪人、死神 28 到 30%）；最強：誤差大時怪人（74%，斧頭慢、較不受誤差影響）。平均一場 7.6 回合（誤差 9），低於 Kiro 要的 8 到 14。盾衛的浮空盾價值這個模擬沒有算進去（機器人不用盾）。
