## Conventions (same as `colab/jobs.json` and the dock requests)

- Flat solid magenta background `#FF00FF`, chroma-keyed afterwards by the main line. No text, no letters, no numbers, no watermark.
- Dark-fantasy 2D cartoon art, thick clean outlines, real material texture (stone grain, brushed iron, worn wood, cloth weave), matching the four unit images.
- Palette: aged stone `#2a2337`, wood `#4a2e1a`, candle gold `#ffcf5a`, pumpkin orange `#ff8a1f`, spectral cyan `#5df2ee`, violet `#a98bff`, black iron `#14111a`.
- No cast shadow outside the object. Keep a 16 px magenta margin around every object so keying does not clip glow.
- Sizes are the generated size. In the game they show at about one third to one half, so they stay sharp on a 2x screen.
- Use an existing Colab image as the style reference where the row says so.
- Every image is reviewed on the real screen before it replaces the code-drawn look. The current drawing stays as the fallback.
