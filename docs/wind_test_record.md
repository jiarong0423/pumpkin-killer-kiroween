## 測試設定（主線在瀏覽器遊戲量得，實際常數）

- GRAVITY = 980 px/s^2，GROUND_Y = 860
- 射手手高：sy = player.y - 110 = 750，手在地面線上方 110 px（落地條件 y_rel >= 110）
- 初速 = power * 13.8 px/s，power = 65；固定步長 1/60 s
- 每步：vx += wind*F*dt；vy += GRAVITY*dt；x += vx*dt；y += vy*dt（y 向下，vy0 = -speed*sin(angle)）
- F = 風力係數候選（48 為目前遊戲值）；風 = 0、+4（順風）、-4（逆風）

## 閉式比對
- 風造成的水平偏移 ~ 0.5*wind*F*t^2 與重算順風偏移最大差 8.56 px（最大相對 1.47%）。閉式一律略低於離散結果，差值吻合半隱式積分的 0.5*a*t*dt 項（a=wind*F，如 30 度 F=48 為 1.79 px），屬步長效應而非錯誤。
- 偏移對 F 的比例（72/48、96/48、140/48）：重算比值與理想比值最大差 5.20e-14
- 主線表 tail 比值（四捨五入至 px 後）範圍 1.497–2.926，理想 1.5/2/2.917
